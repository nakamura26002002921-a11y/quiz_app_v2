# CSVクイズ（PWA版）

Flutter版の元アプリの仕様を踏襲しつつ、ビルド不要のHTML/CSS/JSだけで動く **PWA** として実装したものです。

## 機能

- CSVファイルを読み込んでn択クイズを出題（選択肢の数・出題順のランダム化を設定可能）
- **長押しでテキスト選択** — 問題文・選択肢・解説文はすべて `user-select: text` を指定済みで、スマホでも長押しでコピーできます
- **文字サイズ変更** — ヘッダーの「Aa」ボタンから80%〜180%で全体の文字サイズを変更（設定は端末に保存）
- **出題中にその場でCSVを編集** — クイズ画面のヘッダーにある✎ボタンから、今表示している問題の「問題・解答・解説」を直接編集できます。保存すると選択肢が再生成され、その場で解答し直せます
- **前の問題へ戻る** — 解答済みの選択状態を保持したまま前の問題を見返せます
- **次/前の問題へ移動時に自動で一番上へスクロール**
- **多言語対応** — 日本語 / English / Русский（設定シートの「言語」から切り替え、端末に保存）

ホーム画面はCSV選択のみのシンプルな構成にしています（「読み込み済みのCSVで開始」「CSVを編集する」ボタンは廃止し、編集は出題中にその問題単位で行う方式に変更しました）。

## ファイル構成

```
pwa/
├── index.html            アプリの土台（各jsを読み込み順に読み込む）
├── style.css              スタイル
├── i18n.js                 多言語辞書・翻訳関数
├── state.js                アプリ状態・定数
├── csv.js                  CSV解析・問題読込・選択肢生成
├── utils.js                escapeHtml・トースト等の共通処理
├── render-header.js  共通ヘッダー・設定シート（文字サイズ/言語）
├── render-home.js     ホーム画面
├── render-quiz.js       クイズ画面・問題編集シート
├── render-result.js   結果画面
├── main.js               ルーター・初期化・SW登録
├── manifest.json       PWAマニフェスト
├── service-worker.js  オフラインキャッシュ
├── icons/                   アプリアイコン
└── sample_questions.csv  サンプル問題（動作確認用）
```

`index.html` は `i18n.js` → `state.js` → `csv.js` → `utils.js` → `render-*.js` → `main.js` の順で読み込みます（後続のファイルが前のファイルの関数・変数に依存するため、この順序が必要です）。

## ローカルで試す

```bash
cd pwa
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます（`file://` からはService Workerが動かないため簡易サーバー経由推奨）。

## スマホにインストールする

このフォルダをそのままWebサーバー（GitHub Pages、Netlify、Vercelなど）にアップロードするだけでPWAとして動作します。ビルドは不要です。

- **Android（Chrome）**: サイトを開くとホーム画面追加の案内が出ます。メニュー→「アプリをインストール」でも可
- **iPhone（Safari）**: 共有ボタン → 「ホーム画面に追加」

インストール後はフルスクリーンで起動し、一度開いた後はオフラインでも利用できます。

### GitHub Pagesへのデプロイ例

```bash
cd pwa
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin <あなたのリポジトリURL>
git push -u origin main
```
リポジトリの Settings → Pages で「main / (root)」を指定すれば公開されます。

## CSVフォーマット

- 文字コード: UTF-8（BOM付き・なし両対応）
- 区切り文字: カンマ（`,`）
- 列構成: `問題`, `解答`, `解説`
- 1行目: ヘッダー行（`question,answer,explanation` のような英語ヘッダーでも動作します）
- フィールド内にカンマや改行を含める場合は `"..."` で囲んでください

不備のある行は自動的にスキップされ、トーストで件数が通知されます。個々の問題が誤っている場合は、クイズ画面の✎ボタンからその場で修正できます。
